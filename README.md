# FORM — Injectable peptide concept

A static demo catalog for discussing injectable peptides, with ten profiles, visible evidence and regulatory distinctions, fictional prices, and a simulated shopping bag. No medicines, prescriptions, payments, or real orders are provided.

Files: index.html, style.css, app.js, injectable-vials.png.

Deploy with GitHub Pages using the main branch and the root folder. All asset links are relative, so the site works under a repository subpath.

Sources are linked directly from the catalog and field guide. U.S. context checked September 22, 2026. Research compounds are not represented as proven human treatments.

Hero asset generated with OpenAI image generation: three sealed pharmaceutical vials with cobalt caps on stainless steel against an ultramarine studio background. Original fictional packaging; no real product certification is implied.
